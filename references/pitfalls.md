# 常见坑速查（阶段 2-6）

用户在引导流程中遇到问题时，优先在这里查症状 → 解决方案。所有答案都以真机扫码为准，不要相信模拟器显示。

---

## 阶段 1：注册 AppID 相关

### ❌ 坑 1：AppID 填错

**症状**：WB 出预览二维码时报 "AppID 无效"

**解决**：
- 到 https://mp.weixin.qq.com → 设置 → 基本设置 → 复制正确 AppID（18 位，`wx` 开头）
- 检查有没有多余空格
- 别把 AppSecret（64 位）当 AppID 填

---

## 阶段 2-3：生成项目 & 出预览二维码相关

### ❌ 坑 2：WB 出预览二维码时报打包失败

**症状**：`node scripts/publish.js preview` 报错

**解决**：
- 检查 `project.config.json` 的 AppID 对不对
- 检查是否有语法错误（.js 文件末尾缺分号等）
- 检查 `pages` 目录是否存在，`app.json` 里的 `pages` 路径是否与实际文件对应
- 检查 `.env` 里的上传密钥是不是过期了

### ❌ 坑 3：手机扫码后是空白页

**症状**：扫码能进小程序，但页面没内容

**解决**：
- 检查 `pages/index/index.wxml` 是不是空的
- 检查 `index.js` 的 `data` 字段是否有初始数据
- 检查网络请求是否失败（真机看 console）

### ❌ 坑 4：手机上看不到云端数据，但电脑端能看

**症状**：WB 侧预览正常，手机扫码没数据

**解决**：
- 云开发/云端数据只在真机生效
- 必须真机扫码才能看到真实数据
- 这是设计如此，不是 bug

### ❌ 坑 5：改完代码，效果还是老样子

**症状**：改了 wxml/js，手机上看不到变化

**解决**：
- 每次改完都要重新出预览二维码：`node scripts/publish.js preview`
- 云端代码改动等 30 秒左右生效
- 不要相信缓存——**以真机最新扫码结果为准**

---

## 阶段 4：云后端相关

### ❌ 坑 6：数据表插不进去 / 读不出来

**症状**：前端调 API 报 RLS 拒绝

**解决**：
- 检查 WorkBuddy Cloud Service 的 RLS 策略
- 一般至少需要 3 条策略：`read_all`(SELECT) / `insert_own`(INSERT) / `update_all`(UPDATE)
- 缺 UPDATE 策略会让 upsert 静默失败

### ❌ 坑 7：想跨表查询 / 关联查询报错

**症状**：调 API 时字段名找不到

**解决**：
- 检查表结构定义
- 检查 SQL 里字段名大小写
- 用 `connect_cloud_service` 工具的 `describe_table` 先看下真实 schema

---

## 阶段 5：上传 + 提审相关

### ❌ 坑 8：上传失败，提示密钥错误

**症状**：`node scripts/publish.js upload` 报错

**解决**：
- 到后台「开发设置 → 小程序代码上传」重新生成上传密钥
- 更新 `.env` 里的密钥
- 密钥每次生成后旧的就失效了

### ❌ 坑 9：类目选错导致审核被拒

**症状**：提审后收到 "服务类目不符"

**解决**：
- 重新提审，选正确的类目
- 新类目要资质的，先去申请（一般 3-7 个工作日）
- 参考：
  - 工具类：注册时无需资质，最宽松
  - 教育类：可能需要办学许可证
  - 资讯类：需要 ICP 备案

### ❌ 坑 10：忘了「以真机为准」

**症状**：手机真机看到问题，就以为整个流程有问题

**解决**：
- 记住：**预览二维码 → 真机扫码 = 最终事实**
- 电脑端、模拟器显示的都是辅助信息
- 任何"模拟器正常但真机异常"或反之的情况，以真机为准

---

## 阶段 6：审核通过 → 发布上线相关

### ❌ 坑 11：以为审核通过就自动上线了 ⚠️ 最高频坑

**症状**：审核通过通知收到了，但让朋友搜小程序还是搜不到；后台「版本管理」里能看到「审核版本」但「线上版本」栏还是老版本

**解决**：
- **审核通过 ≠ 上线**，微信**不会自动发布**
- 必须去 mp.weixin.qq.com → 「版本管理」→「审核版本」→ 点「**发布**」按钮 → 二次确认
- 点完等 5-15 分钟微信内部同步，再让朋友搜小程序名
- 微信**没有开放自动发布接口**，任何声称"自动发布上线"的工具都是骗人的
- 这个坑每次更新都会遇到——**发布上线永远是手动一步，且每次都要点**

---

## 通用提示

- **不要**引导用户装微信开发者工具
- **不要**在文档或回复中承诺"自动提审"
- **不要**让 AppID / AppSecret commit 到公开版本库
- **审核时长**引用时保留"官方口径"字样：微信官方口径 1-7 工作日，多数 1-3 天
