# 发布前 Checklist 模板

用户点「提交审核」之前，用这个 checklist 走一遍。

> ⚠️ **术语说明**：微信后台的三个版本叫法是「开发版本 → 审核版本 → 线上版本」，**不要**用"体验版 / 提审"等口语。

---

## 版本信息

- **版本号**：vX.Y.Z（语义化版本）
- **变更说明**：{本次改了什么，30 字内}
- **服务类目**：{按小程序主要用途选}
- **测试账号**：{如需登录，填一个手机号 / 或注明"无需登录"}

---

## 提交前自查（对着勾）

### ✅ 功能自检

- [ ] 首页加载正常，无白屏
- [ ] 所有按钮能点、有反馈
- [ ] 云端数据读写都正常（增/改/删）
- [ ] 手机上真机验证通过（不是模拟器）

### ✅ 内容自检

- [ ] 页面文案无错别字
- [ ] 图片正常显示（无 404 / 无裂图）
- [ ] 无 TODO / 测试数据 / 占位符（比如 "这里是测试数据"）

### ✅ 合规自检

- [ ] 内容不涉及政治敏感、色情、赌博
- [ ] 无诱导分享 / 强制关注等违规行为
- [ ] 用户个人信息处理符合隐私要求
- [ ] 类目资质（如需要）已准备好

### ✅ 技术自检

- [ ] 上传密钥有效（不过期）
- [ ] 域名白名单已配置（如果调外部 API）
- [ ] 云数据库 RLS 策略正确
- [ ] `.env` 文件没被 commit 到公开版本库

---

## 提审后

### 审核时长（官方口径）

| 情况 | 时长 |
|------|------|
| 常规审核 | **1-7 个工作日**（多数 1-3 天） |
| 复杂类目 | 可能 3-7 天 |
| 高峰期 | 可能延长 |
| 付费加急 | 后台「付费管理」或提审页面「审核加急」 |

**来源交叉验证**：
- 微信开放社区官方回复：「小程序正常审核时长 1-7 天」
- 第三方 2026 上架流程：通常 1-3 工作日，复杂类目可能延长至 5 天
- 第三方过审技巧：80% 案例 24h 内完成

### 被驳回的常见原因

1. **类目不符**——重选类目重提
2. **内容不完整**——补齐功能重提
3. **资质缺失**——先申请资质，3-7 工作日
4. **技术原因**（如网络异常）——修复代码重提
5. **合规问题**——按驳回意见整改

### 驳回后

- 后台会告诉你具体原因
- 修改代码 → 走一遍「出预览二维码 → 上传到开发版本 → 手动提审」
- **重新排队**，同样 1-7 工作日

---

## 发布上线（审核通过后）

- 到后台 → 版本管理 → 「审核版本」点「发布」
- 「审核版本」→ 变「线上版本」
- 所有人可以搜到并使用小程序
